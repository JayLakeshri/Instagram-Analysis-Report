# 📸 Instagram Analysis Report — Power BI Dashboard

An interactive Power BI dashboard for analyzing Instagram performance metrics across different post types and content categories.

## 🔍 Overview
This dashboard provides a visual breakdown of Instagram account performance, helping track engagement trends, content category performance, and reach distribution by post type.

## 📈 Key Metrics
- **Total Posts**
- **Total Likes**
- **Total Reach**
- **Avg Engagement Rate**

## 📊 Visuals Included
- Engagement Rate Over Time (trend line)
- Likes By Content Category (bar chart)
- Reach By PostType (horizontal bar chart)
- PostType By Mix (donut chart)

## 🎛️ Interactive Filters
- Post Type slicer (Photo, Carousel, Reel, Video, Story)
- Content Category filter (Beauty, Fashion, Fitness, Food, Home Decor, Lifestyle, Tech, Travel)
- Post Date range slicer

## 🛠️ Tools Used
- Power BI Desktop
- DAX for calculated measures
- Custom slicer styling (Tile layout)

## 📂 File
- `Instagram_Analysis_Report.pbix`

## 🚀 How to Use
1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Explore the dashboard using the interactive filters
